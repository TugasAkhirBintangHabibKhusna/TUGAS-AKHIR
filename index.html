Design and Development of a Manufacturing System Stamping and Rotary Table Based on PLC Haiwell and HMI Monitoring

Introduction

To stay competitive in the industry, production efficiency must be optimized. Automation using PLCs such as integrating stamping with an automatic rotary table can speed up processes and improve accuracy. This project aims to enhance efficiency and reduce errors in production.

How the Sistem Works

When the box is on conveyor 1, it moves to the rotary table and then a proximity sensor triggers the rotary table to rotate 180°. The box is then checked: if metallic, it is pushed to conveyor 2 for stamping; if non-metallic, it is pushed out.

Objectives
  • Design auto stamping & rotary table with Haiwell PLC
  • Increase speed & precision, reduce cycle time
  • Integrate PLC-HMI for real-time control

The figure shows the HMI design for system monitoring

Electrical

The electronic components we used for controlling the system are the Haiwell PLC, a stepper motor driver for stepper motor control, relays, MCB, a PWM pulse controller, and a motor driver.

Conclusion

The system works efficiently, achieves 100% sorting of metal and non-metal boxes, and successfully performs the stamping process, proving its effectiveness in production stability and system accuracy.
