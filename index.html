RANCANG BANGUN IOT TRAINER BOX CONVEYOR & ROTARY ACTUATOR

SISTEM MONITORING & KONTROL TERINTEGRASI BERBASIS SCADA HMI

Jurusan Teknik Elektro - Program Studi Teknik Otomasi Industri Polines
1. Latar Belakang & Tujuan

Kebutuhan media pembelajaran praktikum otomatisasi industri berstandar Industri 4.0 memerlukan integrasi antara perangkat keras aktuator dan sistem monitoring berbasis cloud. Trainer box ini dirancang sebagai media pembelajaran interaktif yang menggabungkan modul conveyor belt dan sistem pemilah posisi rotary actuator secara real-time.

Modul Conveyor Belt
Rotary Sorting System
2. Spesifikasi Hardware & Kelistrikan
  • Kontroler Utama: ESP32 / PLC S7-1200 dengan protokol Modbus TCP/IP.
  • Aktuator: Motor DC Conveyor 24V, Stepper/Servo Rotary, Pneumatic Pusher.
  • Sensor: Induktif, Kapasitif, Photoelectric, dan Sensor Arus ACS712.
  • Power Supply: Dual Output 24VDC & 5VDC dengan perlindungan Fuse & MCB.
Panel Kelistrikan Trainer Box Terintegrasi
3. Metodologi & Alur Kerja

Sistem bekerja dengan mendeteksi benda kerja di atas conveyor, memilah berdasarkan material/warna menggunakan rotary actuator, lalu mengunggah data kondisi operasi ke server cloud.

Diagram Alir Pemrosesan & Komunikasi Data
4. Antarmuka HMI & IoT Dashboard

Dashboard IoT dibangun menggunakan protokol MQTT/HTTP untuk menampilkan visualisasi kecepatan conveyor, penghitung barang (counter), status aktuator, dan grafik konsumsi daya secara visual.

Antarmuka SCADA/HMI Monitoring Real-Time
5. Hasil Pengujian & Analisis

Pengujian dilakukan pada 100 sampel benda kerja untuk mengukur tingkat akurasi pemilahan dan latensi transmisi data IoT.

Parameter Target Hasil Uji Status
Akurasi Sorting > 95% 98.0% Sesuai
Latensi IoT < 500 ms 180 ms Sesuai
Kecepatan Conveyor 0.2 m/s 0.21 m/s Sesuai
Respon Rotary < 1.0 s 0.65 s Sesuai
6. Kesimpulan
  1. Trainer Box berhasil terintegrasi dengan sistem IoT monitoring latensi rendah (180 ms).
  2. Sistem sortir rotary mampu memilah benda kerja dengan tingkat akurasi tinggi sebesar 98%.
  3. Alat layak digunakan sebagai media praktikum berbasis industri 4.0 di Jurusan Teknik Elektro Polines.
