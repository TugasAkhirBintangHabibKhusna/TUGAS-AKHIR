IoT SORTING TRAINING SET: PORTABLE TRAINER BOX WITH CONVEYOR ACTUATOR

Introduction

The demand for practical learning tools in industrial automation is increasing. This project introduces the "IoT Sorting Training Set," designed as a portable trainer box equipped with a 75cm conveyor to simulate real-world automated sorting processes. It aims to provide an interactive and mobile educational medium for students studying IoT and control.

How the System Works

Objects are placed onto the 75cm conveyor actuator. As they move, sensors integrated into the portable trainer box detect the object's properties (e.g., material or height). The control unit processes this data to trigger the sorting mechanism, pushing objects into their designated categories while sending real-time data to the IoT dashboard.

Objectives
  • Design a portable trainer box for IoT-based sorting simulations.
  • Integrate a 75cm conveyor as the main system actuator.
  • Develop an interactive learning tool with real-time IoT monitoring capabilities.
IoT Interface

The figure shows the IoT Dashboard design for real-time monitoring.

Hardware System

The system is housed in a compact portable box containing the main controller (PLC/Microcontroller), motor drivers for the 75cm conveyor, proximity sensors, relays, and IoT communication modules to ensure seamless sorting operations.

Conclusion

The IoT Sorting Training Set functions effectively as a mobile learning medium. The 75cm conveyor and sorting actuators work precisely to categorize objects, while the IoT integration successfully provides real-time data monitoring, making it highly suitable for educational purposes.
